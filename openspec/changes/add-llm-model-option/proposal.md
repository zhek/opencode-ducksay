# Proposal

## Why

Каждая шутка уточки сейчас генерируется моделью, выбранной в активной сессии. Шутка — короткая реплика на сто символов, и
платить за неё ценой рабочей модели (например, Opus класса) незачем: это тихий, но постоянный расход на каждом
завершённом ходе. Пользователь, который хочет экономить, должен иметь возможность направить шутки на дешёвую или
бесплатную модель, не меняя модель самой сессии.

## What Changes

- Новая опция плагина `llmModel` — имя модели, которой поручается запрос шутки, в формате `"провайдер/модель"`
  (например, `"opencode/big-pickle"`).
- Опция задана — запрос шутки уходит только в эту модель. Любая неудача (модели нет, ключа нет, сервер вернул ошибку,
  ответ пустой или не пришёл вовремя) показывается как `Quack-quack!`: без тоста, без повторного запроса и без тихого
  возврата на модель сессии.
- Опция не задана (пропуск, `null`, пустая или пробельная строка, не строка) — поведение не меняется: шутку пишет
  модель активной сессии, а если в сессии модели нет — модель по умолчанию сервера.
- Непустая строка не по формату (`"opus"` без провайдера) считается непригодной моделью: утка молчит с `Quack-quack!`,
  а не подставляет модель сессии.
- `docs/configuration.md` и `docs/configuration.ru.md` получают раздел опции с примером экономии
  `"llmModel": "opencode/big-pickle"`; `README.md` и `README.ru.md` — имя опции в перечне; `CHANGELOG.md` — запись в
  `## Unreleased` → `### Added`.

## Capabilities

### New Capabilities

Нет: поведение принадлежит существующей возможности боковой панели.

### Modified Capabilities

- `ducksay-sidebar`: требование «Шутка запрашивается у модели текущей сессии» меняется — при заданной `llmModel` запрос
  уходит только в неё; добавляется требование «Модель запроса шутки настраивается» с точным именем опции, форматом
  значения и явным отсутствием дефолта.

## Impact

- `src/options.ts` — новый резолвер `resolveLlmModel` по образцу `resolveLlmTimeout`.
- `src/joke.ts` — `createJokeGenerator` получает разобранный `ModelRef` и передаёт его в `session.create` вместо модели
  сессии; при отсутствии опции остаётся текущее поведение.
- `src/tui.tsx` — чтение опции в `setup` и передача её в генератор.
- Тесты: `test/options.test.ts` (разбор значения), `test/joke.test.ts` (какая модель уходит в `create`, ошибка → `undefined`).
- Документация и `CHANGELOG.md`; версия пакета не двигается.
- Демо-gif, точки входа и состав пакета не меняются — внешний вид и загрузка плагина остаются прежними.
