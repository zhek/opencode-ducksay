# Proposal

## Why

Текущие значения по умолчанию ощущаются подобранными не под этот сценарий: утка пересекает полосу за 2,4 секунды, а на шутку отводится 25 секунд, чего не всегда хватает медленной модели. Отдельно маркер вопроса сменяет четыре кадра строго через 300 мс, поэтому «ребро» `!` занимает половину цикла и переворот знака читается как слайд-шоу из четырёх символов, а не как вращение.

## What Changes

- Скорость плавания по умолчанию меняется с `12` на `10` колонок в секунду. Вода наследует новый темп автоматически, потому что он выводится из `swimSpeed`.
- Таймаут ответа LLM по умолчанию меняется с `25` на `60` секунд. Верхняя граница `120` секунд и правила обработки некорректных значений не меняются.
- Маркер ожидающего вопроса получает более плавный переворот: кадры дублируются, шаг уменьшается с `300` до `150` мс. Лица `?` и `⸮` держатся по `300` мс, рёбра `!` — по `150` мс; полный цикл занимает `900` мс вместо `1200` мс.
- Видимая последовательность знаков не меняется: `?` → `!` → `⸮` → `!`. Колонка маркера, его цвет и высота раздела остаются прежними.
- Новых опций нет; существующие `swimSpeed`, `llmTimeout` и `llmContextDepth` продолжают работать как раньше, меняются только значения по умолчанию и темп маркера.

## Capabilities

### New Capabilities

Нет новых возможностей: изменения уточняют уже существующий раздел.

### Modified Capabilities

- `ducksay-sidebar`: меняются значения по умолчанию для скорости плавания и таймаута LLM, а также каденция кадров маркера ожидающего вопроса.

## Impact

- `src/options.ts`: значения `DEFAULT_SWIM_SPEED` и `DEFAULT_LLM_TIMEOUT_MS`.
- `src/question.ts`: массив кадров маркера и интервал между кадрами.
- `test/options.test.ts`, `test/question.test.ts`, `test/section.test.tsx`, `test/setup.test.ts`: явные проверки новых значений по умолчанию и выдержек кадров; тестовые фикстуры, которые сейчас исходят из скорости `12`.
- `README.md`, `README.ru.md`, `docs/configuration.md`, `CHANGELOG.md`: пользовательское описание новых значений по умолчанию и более плавного маркера.
- `openspec/specs/ducksay-sidebar/spec.md`: обновление требований о скорости, таймауте и кадрах маркера.
- Зависимости, публичный API и формат конфигурации не меняются.
