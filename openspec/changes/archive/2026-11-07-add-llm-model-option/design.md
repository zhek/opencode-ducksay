# Design

## Context

Сейчас `createJokeGenerator` создаёт временную сессию с `model: source.session?.model` и сразу шлёт в неё промпт
(`src/joke.ts`). Опции плагина читаются один раз в `setup` (`src/tui.tsx`) защитными резолверами из `src/options.ts`:
отсутствие значения означает дефолт, некорректное значение не ломает плагин. Любая неудача запроса уже схлопывается в
`undefined`, и облачко показывает `Quack-quack!`; отдельного пути для «модель не найдена» нет и не требуется.

Клиент плагина умеет `model.list()`, но в этом change он не используется — см. решение 5.

## Goals / Non-Goals

**Goals:**

- Добавить опцию `llmModel` так, чтобы при её отсутствии не менялось ровно ничего.
- Свести «модель не найдена» к уже существующему пути ошибки, без новых тостов и без валидационных запросов.
- Сохранить образец резолверов: чистые функции в `options.ts`, проверяемые без сети и рендера.

**Non-Goals:**

- Eager-валидация по `client.model.list()` и кэш списка моделей.
- Вшитая в плагин дефолтная модель: пример `opencode/big-pickle` живёт только в документации.
- Поддержка `variant`/`#` в значении опции: берётся только пара «провайдер/модель».
- Изменение демо-gif, точек входа, состава пакета и версии.

## Decisions

### 1. Резолвер возвращает разбор, а не строку

`resolveLlmModel(options)` возвращает размеченное объединение:

```ts
type LlmModelChoice =
  | { kind: "session" }                       // опции нет — как сегодня
  | { kind: "model"; model: ModelRef }        // опция разобрана — шлём только сюда
  | { kind: "unusable" }                      // опция есть, но непригодна
```

Три состояния нельзя выразить одним `ModelRef | undefined`: `undefined` должен значить «опции нет, работаем как
раньше», а строка без провайдера обязана давать `Quack-quack!`, не подставляя модель сессии. Альтернатива — `null` для
«непригодна» и `undefined` для «нет» — короче, но легко перепутать местами при вызове; объединение читается на месте
использования.

Правила разбора: значение приводится к строке и обрезается по краям; пустая строка и не строка — `session`; строка без
`/`, с пустым провайдером или пустой моделью — `unusable`; иначе первая `/` делит строку на `providerID` и `id`, а
остаток (включая `:free`) целиком становится `id`. `variant` не заполняется.

### 2. Непригодная модель отсекается до запроса

Генератор получает разобранный выбор и в случае `unusable` возвращает `undefined` сразу, не создавая временную сессию:
облачко показывает `Quack-quack!`, серверных вызовов и уборки временной сессии нет. Так «опечатка в опции» не тратит ни
запрос, ни таймаут, и не оставляет мусора.

### 3. При отсутствии опции остаётся ровно текущий код

`kind: "session"` означает `model: source.session?.model` в `session.create` — тот же объект, что и сегодня, вместе с
серверным дефолтом, когда у сессии модели нет. Опция читается в `setup` и передаётся в `createJokeGenerator` одним
полем.

### 4. Опция читается при загрузке плагина

Как и остальные опции, `llmModel` фиксируется на старте: смена значения требует перезапуска OpenCode. Это уже описано
для всех опций в `docs/configuration.md`, отдельной механики не вводим.

### 5. Eager-валидация отклонена

`client.model.list()` доступен, но проверка «есть ли модель в каталоге» не отвечает на главный вопрос «работает ли она»
— ключи провайдера проверяются только на запросе, — добавляет шов `model.list` в `JokeClient`, кэш и инвалидацию, а
пользовательского эффекта не даёт: при любой неудаче уже требуется тот же `Quack-quack!` без тоста. Отказ от проверки
оставляет одну ловушку `catch`, которая и так существует.

## Risks / Trade-offs

- [Опечатка в опции молча даёт `Quack-quack!` на каждом ходе] → сознательный выбор: тостов нет; образец значения и
  пример в `docs/configuration.md` снижают вероятность опечатки, а поведение зафиксировано в спеке.
- [Разбор не проверяет существование провайдера и модели] → существование и доступность решает сервер; ошибка уходит в
  общий путь `Quack-quack!`, как и смерть модели посреди работы.
- [Модель может не знать языка пользователя] → правило языка остаётся в промпте; пример в документации использует
  модель, которую сервер и так выбирает по умолчанию.
- [Первая `/` как разделитель] → совпадает с серверным форматом ссылки на модель (`/^[^#]+\/[^#]+$/`); идентификаторы
  моделей `/` не содержат.
