# Конфигурация и опции

[English version](configuration.md)

У `opencode-ducksay` четыре опции: `swimSpeed`, `silent`, `llmTimeout` и `llmContextDepth`. Все они необязательные. Без
настройки уточка плывёт со скоростью 10 колонок в секунду, говорит, ждёт шутку шестьдесят секунд и читает по два
последних сообщения каждого типа.

В покое после завершённого хода уточка просит у модели текущей сессии короткую шутку. Запрос собирается локально из
последних сообщений, названия сессии, проекта и ветки; вывод инструментов, содержимое файлов и diff не отправляются.
Запрос идёт к модели, выбранной в сессии, а если там ничего не выбрано — к модели сервера по умолчанию, и не добавляет
сообщение в историю. Пока ответ в пути, облачко говорит `Quack` с растущим многоточием, а если запрос завершился ошибкой,
ничего не вернул или не уложился в таймаут, уточка говорит `Quack-quack!`. `silent: true` — выключатель речи. До первого
завершённого хода уточка отдыхает молча: шутку запускает завершённый ход, а не первое плавание.

## Включение плагина

`~/.config/opencode/cli.json`:

```json
{
  "plugins": ["opencode-ducksay"]
}
```

`cli.json` бывает только глобальным — локального аналога в проекте нет. Настройки CLI живут в этом одном файле, поэтому
включённый там плагин остаётся активным и с удалённым сервером, и с локальным.

После правки файла перезапустите OpenCode. Для опубликованного пакета OpenCode принимает записи `opencode-ducksay` и
`opencode-ducksay@<версия>`.

## `swimSpeed`

Скорость уточки в колонках в секунду. Полоса панели шириной около 29 колонок, поэтому со значением по умолчанию `10`
пересечение занимает примерно 2,9 секунды.

То же число задаёт темп воды: узор идёт так, что за одно пересечение панели успевает пройти ровно один полный цикл.
Отдельной опции для воды нет, поэтому `swimSpeed` — единственное, что управляет движением уточки и воды. Говорит ли
уточка, решает не он.

```json
{
  "plugins": [{ "package": "opencode-ducksay", "options": { "swimSpeed": 24 } }]
}
```

| Значение | Результат |
| --- | --- |
| не задано | `10` колонок в секунду |
| `0` | Уточка не двигается и вода не едет; речь продолжает работать, маркер вопроса продолжает меняться |
| `1` … `120` | Столько колонок в секунду; всё, что выше `120`, ограничивается `120` |
| число в кавычках, `"24"` | Читается как то же число |
| всё остальное — отрицательное число, слово, пустое значение | Возврат к `10` |

Число без кавычек — обычная запись. Кавычки допускаются, потому что это частая опечатка, и молча подменить запрошенные
`24` значением по умолчанию было бы хуже, чем прочитать написанное. Пустое значение считается «не задано», а не `0`,
поэтому пустое поле не может тихо остановить уточку.

При `0` уточка и вода стоят на месте, но облачко продолжает работать: многоточие ожидания и печать шутки идут по своим
таймерам, а маркер над клювом продолжает меняться, пока вопрос ждёт ответа. Чтобы уточка ещё и молчала, задайте
`silent: true`.

Небольшая скорость замедляет не только уточку, но и воду: при `1` обе почти не движутся все полминуты, пока идёт
пересечение. Вода останавливается и тогда, когда панель уже рисунка уточки: плыть уточке некуда, и воде не с чем
соразмерять свой ход. Панель уже рисунка не оставляет места и для облачка, поэтому шутку там уточка не просит; маркер
вопроса при этом работает.

## `silent`

Выключает речь уточки. По умолчанию `false`: после завершённого хода уточка просит у модели шутку и показывает облачко.
При `true` нет ни облачка, ни текста, ни запроса к модели. Уточка и вода по-прежнему двигаются по `swimSpeed`.

```json
{
  "plugins": [{ "package": "opencode-ducksay", "options": { "silent": true } }]
}
```

| Значение | Результат |
| --- | --- |
| не задано | `false` — уточка говорит после завершённого хода |
| `false` | Уточка говорит |
| `true` | Уточка молчит: ни облачка, ни текста, ни запроса |
| строка `"true"` в любом регистре и с пробелами по краям | Читается как `true` |
| `0`, `"false"`, другое слово, объект | Речь остаётся включённой; опечатка не выключит уточку случайно |

Опция, как и остальные, читается при загрузке плагина, поэтому после её изменения нужен перезапуск OpenCode. Маркер
вопроса от `silent` не зависит: пока форма ждёт ответа, маркер продолжает меняться, даже если уточка молчит.

Чтобы уточка и не двигалась, и не говорила, задайте обе опции: `{ "swimSpeed": 0, "silent": true }`. До появления этой
опции `swimSpeed: 0` выключал и шутки; теперь это не так.

## `llmTimeout`

Сколько секунд уточка ждёт шутку. Отсчёт начинается, когда запрос уходит к модели, а не пока плагин читает сессию
локально, поэтому большой контекст не съедает время ответа.

```json
{
  "plugins": [{ "package": "opencode-ducksay", "options": { "llmTimeout": 10 } }]
}
```

| Значение | Результат |
| --- | --- |
| не задано | `60` секунд |
| конечное положительное число | Столько секунд |
| число в кавычках, `"10"` | Читается как то же число |
| `0`, отрицательное число, пустое значение или не число | Возврат к `60` секундам |
| значение больше `120` | Ограничивается `120` секундами |

Когда таймаут истекает, запрос отменяется, и облачко показывает `Quack-quack!`. Повтора до следующего хода нет.

## `llmContextDepth`

Сколько последних сообщений каждого типа попадает в запрос за шуткой: сообщения пользователя и ответы ассистента
считаются отдельно, поэтому значение по умолчанию `2` означает два сообщения пользователя и два ответа ассистента.
Название сессии, проект и ветка добавляются всегда, когда они есть, при любом значении.

```json
{
  "plugins": [{ "package": "opencode-ducksay", "options": { "llmContextDepth": 3 } }]
}
```

| Значение | Результат |
| --- | --- |
| не задано | `2` сообщения каждого типа |
| целое число от `1` до `10` | Столько сообщений каждого типа |
| число в кавычках, `"3"` | Читается как то же число |
| значение больше `10` | Ограничивается `10` |
| `0`, отрицательное число, дробное число, пустое значение или не число | Возврат к `2` |

Отправляется только текст сообщений. Рассуждения, вызовы инструментов, их вывод, содержимое файлов и diff не попадают.
Шутка пишется на языке последнего сообщения пользователя, а если язык по нему неочевиден — на языке предыдущих
сообщений.

Подстановка переменных к `cli.json` **не** применяется: `"{env:DUCK_SPEED}"` доходит до плагина буквальным текстом, а
это не число, поэтому используется значение по умолчанию. Если значение нужно держать в одном месте, храните его в
файле, а не в переменной.

Что стоит знать:

- Опции читаются при загрузке плагина, поэтому после их изменения OpenCode нужно перезапустить.
- `{"plugins": ["opencode-ducksay"]}` остаётся рабочим — объектная форма нужна только чтобы передать опции.

У OpenCode есть собственная глобальная настройка `animations` в `cli.json`, которая выключает анимации интерфейса.
Плагины её не читают, поэтому на уточку она не влияет: `swimSpeed: 0` — выключатель анимации уточки и воды, а
`silent: true` — выключатель речи.

## Отключение плагина

Поставьте `-` перед записью:

```json
{
  "plugins": ["-opencode-ducksay"]
}
```

Это выключает плагин, не удаляя его, и работает вместе с подстановочным знаком:

```json
{
  "plugins": ["*", "-opencode-ducksay"]
}
```

Чтобы убрать плагин совсем, удалите запись и перезапустите. Состояние в проекте не пишется, поэтому переносить обратно
нечего.

## `session.sidebar`

Это настройка OpenCode, а не плагина. Она управляет панелью, в которой рисуется уточка, и живёт в
`~/.config/opencode/cli.json` под ключом `session`:

```json
{
  "session": { "sidebar": "auto" }
}
```

Она не идёт в `opencode.json`, где ключа `session` нет вовсе: неизвестный файлу ключ ни на что не влияет, и ничто об
этом не сообщает. Опции плагина лежат в том же `cli.json` и перечислены выше.

| Значение | Результат |
| --- | --- |
| `"auto"` (по умолчанию) | Панель показывается, когда для неё есть место. Уточка появляется вместе с ней. |
| `"hide"` | Панель не рисуется. Уточка не появляется вовсе. |

Ни одно значение не включает панель принудительно, поэтому `"auto"` показывает её, только когда терминал достаточно
широк — см. следующий раздел.

OpenCode также даёт `session.sidebar.toggle` как настраиваемую комбинацию клавиш, в том же файле под `keybinds`. Её
значение по умолчанию не объявлено в опубликованной схеме конфигурации OpenCode, а `Escape` на 2.0.17 панель не
переключает.

## Когда раздела нет

Уточка появляется только там, где OpenCode показывает панель:

- на экране сессии — на домашнем экране её нет;
- когда терминал достаточно широк, чтобы панель вообще появилась. Точный порог — дело OpenCode, и он меняется от версии
  к версии; на 2.0.17 это 121 колонка, а на 120 и меньше панели нет и сообщения о причине тоже;
- пока прокрутка панели не ушла за него.

## Локальная разработка

Настройка не нужна, и ничего за пределами репозитория не меняется. `.opencode/plugins/ducksay/tui.ts` реэкспортирует
точку входа из `src/tui.tsx`, и OpenCode находит эту директорию при запуске.

Чтобы перестать пользоваться локальной копией, удалите директорию `.opencode/plugins/ducksay`.
